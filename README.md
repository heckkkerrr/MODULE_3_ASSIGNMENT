## Description
This repository contains simple Java answers and practical programs for the supplied Module 3 assignment.

## Topics
Threads, synchronization, locks, streams, file handling, and java.lang/java.util.regex examples.

## Structure
- `Assignment_Answers.md` contains concise answers and the question-to-file map.
- `src/` contains small runnable Java examples.
- `pom.xml` is included where Maven is required.

## Prerequisites
Java 17 or later. Module 5 practical Maven examples also require Maven.

## Compile and run
From `src`, compile with `javac *.java` and run a class with `java ClassName`. Some examples create files in the current directory. Intentional deadlock examples are labelled and should only be run for a short demonstration.
